1. Общие положения

Настоящая Политика описывает обработку информации в мобильном приложении DriveDoc (далее — «Приложение»). Приложение предназначено для самостоятельного учёта рабочих смен водителя, доходов, расходов, заказов, целей и GPS-маршрутов. Разработчик Приложения — лицо, указанное в карточке DriveDoc в RuStore. По вопросам обработки информации можно обратиться на rustamnakiev59@gmail.com.

Политика относится к версии 1.0.2 (71). Возможности будущих версий, включая регистрацию и серверную синхронизацию, в неё не включены.

2. Какие данные обрабатываются

В зависимости от используемых функций Приложение может обрабатывать:

  • Данные смен и финансов: даты и продолжительность смен, суммы доходов, количество заказов, бонусы, чаевые, комиссия агрегатора, налоги, расходы, цели, штрафы, заметки и другие значения, внесённые пользователем или импортированные с его разрешения.
  • Данные местоположения и маршрута: координаты, время GPS-точек, длину пути, сведения о движении и паузах. Эти данные используются при работе записи маршрута и отображении карты.
  • Данные с экрана Яндекс Про: с разрешения пользователя служба специальных возможностей Android может считывать отображаемые показатели из приложения Яндекс Про, включая текущую сумму, количество заказов и дневную сводку. При необходимости Приложение может обрабатывать снимок соответствующего экрана и распознавать текст локально на устройстве.
  • Данные пользовательских файлов: содержимое выбранных пользователем изображений, резервных копий и экспортируемых файлов, необходимое для импорта, распознавания или восстановления записей.
  • Настройки Приложения: параметры оформления, отображения, уведомлений, карт и других функций.
  • Сообщения пользователя разработчику: адрес электронной почты и информация, которую пользователь самостоятельно указывает в обращении.

Приложение не предназначено для чтения личной переписки, контактов и содержимого других приложений через службу специальных возможностей. Обработка экрана агрегатора ограничена поддерживаемым приложением Яндекс Про и связанными с ним функциями учёта.

3. Для чего используются данные

Информация используется для работы функций Приложения: расчётов доходов и расходов, сохранения смен, построения графиков и отчётов, отображения и записи маршрутов, автоматического заполнения значений из Яндекс Про, создания резервных копий, экспорта и восстановления данных, а также работы пользовательских настроек и уведомлений.

В версии 1.0.2 (71) регистрация пользователя и передача базы его смен на сервер разработчика не предусмотрены. В исходном проекте этой версии не интегрированы рекламные SDK и отдельные сервисы аналитики действий пользователей.

4. Где хранятся данные и когда происходит передача

Основные данные смен, финансов, целей, GPS-треков и настроек сохраняются локально на устройстве. Распознавание текста с экрана агрегатора выполняется локально; Приложение не направляет такие снимки разработчику для распознавания.

Онлайн-карты. Для загрузки картографической подложки Приложение может обращаться через MapLibre к поставщику картографических данных VersaTiles (tiles.versatiles.org). При таких запросах поставщик может получать технические данные соединения, включая IP-адрес, время обращения и запрашиваемые участки карты. Эти сведения обрабатываются поставщиком в соответствии с его собственными правилами. Пользователь может применять заранее загруженные офлайн-карты, если они доступны для соответствующей области.

Экспорт и передача файлов. Если пользователь самостоятельно экспортирует, сохраняет или отправляет резервную копию, отчёт либо иной файл, его содержимое может быть доступно выбранному пользователем приложению или облачному сервису. Приложение не контролирует дальнейшую обработку данных таким получателем.

Обращения по электронной почте. При обращении на контактный адрес информация передаётся через выбранный пользователем почтовый сервис.

5. Разрешения устройства

В зависимости от выбранных функций Приложение может запрашивать разрешения на местоположение, уведомления, отображение поверх других окон и использование службы специальных возможностей для чтения показателей Яндекс Про. Фоновая запись маршрута и работа таймера могут использовать системную службу Android.

Разрешения выдаются и отзываются в настройках Android. Отключение разрешения может ограничить связанную с ним функцию, но не обязательно делает недоступными остальные возможности Приложения.

6. Хранение, безопасность и удаление

Данные хранятся в локальном хранилище Приложения, пока пользователь не удалит соответствующие записи либо данные приложения. Для защиты применяются штатные механизмы изоляции Android; сетевые обращения Приложения настроены на защищённые соединения.

В разделе «Инфо» → «Сброс» предусмотрено удаление смен, штрафов, налоговых платежей, целей и GPS-треков. Настройки и скачанные офлайн-карты при таком сбросе могут сохраняться. Удаление Приложения обычным способом, как правило, удаляет его локальные данные с устройства. Ранее экспортированные пользователем файлы и копии в сторонних сервисах необходимо удалять отдельно.

Разработчик не может дистанционно удалить информацию, которая находится только в локальном хранилище устройства пользователя.
